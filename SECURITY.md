## Reporting a vulnerability

These are personal projects. If you find a security issue, please open a
[private security advisory](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
on the affected repository rather than a public issue. Expect a best-effort
response — there is no SLA.

## Supported versions

Only the latest release of each project receives fixes.
